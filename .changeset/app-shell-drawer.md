`AppShell` takes `collapseTo="drawer"`: below `collapseBelow` the sidebar is hidden and a menu button at the start of the header opens the same content in a `Drawer` from the start edge; following a link closes it. `menuLabel`, `menuOpen`, `defaultMenuOpen` and `onMenuOpenChange` name and control it. The default, `collapseTo="stack"`, is unchanged.
